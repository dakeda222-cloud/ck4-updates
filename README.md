# 징기스칸 IV 팬 리마스터 배포

비공식 팬 프로젝트의 런처 배포 저장소입니다. 런처는 Releases에서 파일을 확인하고 내려받습니다.

- `full-v*`: 최초 전체 설치
- `game-v*`: 이후 변경 파일 업데이트
- `v*`: 추가 콘텐츠 배포

이 프로젝트는 《징기스칸 IV》의 오랜 팬이 개인적인 애정을 담아 제작한 비공식 팬 리마스터·모드입니다. 원작 제작사·배급사 또는 권리자가 제작·후원·승인한 공식 프로젝트가 아닙니다.

이 프로젝트는 판매·광고·후원을 받지 않으며, 영리 목적으로 운영하지 않습니다. 원작 게임과 그 명칭·이미지·음악 등 원저작물에 관한 권리는 각 권리자에게 있습니다.

권리자의 이용 중단 또는 삭제 요청을 받으면 관련 자료의 공개 배포를 즉시 중단하고, 운영자가 직접 관리하는 파일과 게시물을 지체 없이 삭제하겠습니다.

이 안내는 원저작물의 이용 허락을 의미하지 않습니다.
